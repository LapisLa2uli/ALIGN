# 修正后 40 条数据的标注复核

结论：标签存在确定的重复记录、重复覆盖和谱面字段不一致；部分错音标注有时间/选区疑点。不能据此给出整套标注的人工准确率，也不能把自动音高检测当作人工听审。

检查范围是 40 份 `labels.json`、共 63 条各类标注。对全部 40 条音频做了独立于两个 baseline 的 YIN 基频筛查，再对 36 个重点窗口做 pYIN 核查；两种方法属于同一算法家族，不能视为两个独立标注者。原标签及正式模型评估结果均未修改，文件哈希见 `integrity.json`。

打开 [review.html](review.html) 可播放八个重点片段，并查看波形、基频与所选谱面音高。音频截取保留原响度与音调；横坐标是原录音时间。

| 样本 | 位置 | 发现 | 结论强度 |
|---|---|---|---|
| 002 | 67.6397–67.6601 s | 四条 missed_note 内容完全一致，仅 ID 不同 | 确定的重复记录，不能按四个独立事件计数 |
| 005 | 13.5414–14.9662 s | 一条整体 wrong_note 覆盖另两条 wrong_note | 确定重复覆盖，需要统一区间/逐音符计数政策 |
| 039 | 2.4552–2.5671 s | 所选谱面实际发声 MIDI 75，pYIN 中位 75.1；邻近序列可对应 | 较强的错标或时间/选区偏移疑点；仍需复听 |
| 036 | 5.3435–5.6153 s | 两条 wrong_note 落在低能量区域，无可靠有声基频帧 | 应优先核对时间边界；不能把“无基频”直接当作“无错误” |
| 031（空标注） | 25.73–25.85 s | 局部偏高约 60 音分，邻近音符也偏高约 13–36 音分 | 音准复听候选，不是已确认的 wrong_note 漏标 |
| 007（空标注） | 23.12–23.24 s | 估计音高接近预期第 3 泛音 | 泛音误判/过吹歧义，不能自动补标 |
| 035 | 两条 repetition | 缺少 extra_copies、repeats_label_range | 评分信息不完整，不等于听觉判断错误 |

031 的初筛整数音高把 MIDI 65.6 四舍五入成 66，曾表现为“高一个半音”。精查后已撤回这种表述：实际约 +60 音分，频谱主峰约 362 Hz，也支持连续音高偏高而非已确认的半音错音。

**谱面字段问题：** 23 条标签的存储音高列表与当前谱面范围不一致，5 条 UI 核心选择与核心范围不一致，2 条重复标签缺少 canonical 计分需要的字段。这些集合可重叠，且包括重复记录，不能相加或据此计算音乐标注错误率。问题可能来自标注工具、乐谱版本或索引迁移；不等于标注者听错。

`core_note_ids` 使用包含休止符的 UI 事件 ID，而 `score_part` 使用发声音符索引。本次已用标注工具的实际事件映射核对，没有把两套编号天然不同误报为问题。

对 19 条空标注音频的自动筛查发现，若干大音程“异常”在 pYIN 复查中回到预期音高，属于估计器的八度/次谐波问题。没有依据宣称这 19 条都存在漏标，也没有完成足以证明它们全无错误的人工复听。click、squeak、bad_timbre、bad_start、sliding、rhythm_error 等需要听感、节奏上下文和明确标注规则，未依据基频给出正确/错误判决。

文件：

- `label_review.csv`：全部 63 条标注的时间、结构问题及有针对性的基频核查数据。
- `structure.json`：通过 UI 真实索引映射的谱面审计结果。
- `pitch_review.json`：全量粗筛结果，包含尚未证实及已被复查削弱的候选，不能直接当错标清单。
- `pyin_checks.json`：36 个重点窗口的复查结果。
- `fft_031.json`：031 局部频谱检查。
- `clips/`、`figures/`：复听片段和配套图。
