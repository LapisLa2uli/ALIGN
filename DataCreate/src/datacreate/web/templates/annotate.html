Hotkeys

  • 1-9: assign label type to selected region(s)
  • Space: play/pause (works unless typing in a text field)
  • Ctrl+Z: undo last label edit
  • Ctrl+A: select all visible labels
  • Delete / Backspace: delete selected region(s)
  • Drag scrubber to move playhead
  • Drag waveform to add a label (works over unselected labels)
  • Double-click a region to select it; only selected labels can be moved
  • Click overlapping labels: choose which one to select
  • Click empty waveform to deselect
  • Ctrl+click: toggle region in multi-select
  • Ctrl+drag on waveform: select multiple regions
  • Shift+right-drag: rectangle-select labels
  • Repetition labels: link the original passage before saving
  • Ctrl+wheel on waveform: zoom; wheel: scroll horizontally
